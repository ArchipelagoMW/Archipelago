# Twilight Princess

Twilight Princess support for Archipelago.

## Installation and usage

Twilight Princess is included directly in Archipelago. No separate APWorld
installation is required.

See the [setup guide](docs/setup_en.md) for game-specific setup instructions.

## What does randomization do to this game?

Items are shuffled between locations in the game, so each playthrough is
different. Randomized locations can include chests, items received from NPCs,
Golden Bugs, Poes, and more.

The randomizer also uses several quality-of-life features, including an
opened world, reduced cutscenes, and transform-anywhere functionality.

## Which locations are randomized?

Twilight Princess contains a large number of randomized locations, including
chests, NPC rewards, collectibles, and other checks. World options determine
which categories of locations can contain progression and useful items.

## What is the goal?

Reach and defeat Ganondorf in Hyrule Castle. The Master Sword is required;
the Light Sword upgrade is not required.

## What do other players' items look like?

Items belonging to other players appear as green rupees in-game. Collecting
one sends the corresponding location check to Archipelago.

## What happens when I receive an item?

Received items are placed into a queue and given to Link in-game. Link may
hold an item out briefly while receiving it.

## Do the in-game hints mean anything?

No. The in-game hints are based on the underlying randomized locations and
currently do not represent the Archipelago item placed there.
