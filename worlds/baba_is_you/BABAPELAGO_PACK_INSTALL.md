These instructions are no longer necessary, since you can now use the /installpack command in the client to do this process automatically. However, if this process isn't working for whatever reason, or you would simply prefer to do it manually.

1. Download the pack manually from the GitHub releases page.

2. Navigate to Baba Is You's "worlds" folder, located in "Data". On Steam, you can find this by selecting the Gear icon for the game in the library, and selecting "Manage -> Browse local files." On Mac, you'll also need to right click Baba Is You.app and select "Show Package Contents", then navigate to Resources. 

3. Once you have found the "worlds" folder, make a copy of the folder called "baba", which holds the levels in the base game. Rename the copy to "babapelago" (case sensitive).

4. Finish installing the Babapelago level pack by extracting the contents of the "babapelago.zip" file to the worlds folder. This should ask if you'd like to replace files, and you MUST answer YES. This is VERY important! If you don't replace the files, the mod will not load.

NOTE: When a new version releases, you don't need to go through the entire levelpack installation process again. Simply take the new files from babapelago.zip and replace the old files in your existing babapelago world folder.
