# Game Dev Tycoon Setup Guide

## Required software

- [Archipelago](https://github.com/ArchipelagoMW/Archipelago/releases) 0.6.3 or newer
- Game Dev Tycoon on Steam (Windows or Linux)
- The `GDT_Archipelago` mod, from the Game Dev Tycoon zip on the
  [releases page](https://github.com/ioicaleb/game-randomizers/releases)
- If your Archipelago doesn't include Game Dev Tycoon yet, the `gamedevtycoon.apworld` from the same zip, placed in
  Archipelago's `custom_worlds` folder

## Setup

1. Copy the `GDT_Archipelago` folder into the game's `mods` folder. In Steam, right-click the game, choose Manage, then
   Browse local files to find it.
2. Enable the mod in the game's Mods menu and restart the game.
3. Start the game and enter the server address, slot name and password in the overlay (F1 shows or hides it).

## Connecting

Use the address and port your host gave you. If the connection drops, the client keeps retrying and catches up on
anything you did while offline.
