# Archipelago Randomizer für Anno 1800 - {{ mod_name }}

Diese Mod randomisiert Anno 1800 und ermöglicht die Kommunikation mit einer Archipelago Multiworld.
Sie wurde für den Slot {{ slot_name }} auf dem Seed {{ seed_name }} für Archipelago Version {{ ap_version }} generiert.

Diese Mod kann alleinstehend ohne Archipelago Klienten oder Server gespielt werden, falls sie beim Generieren der
einzige Slot war.

## Kompatibilität
### DLCs
Aktuell ist diese Mod nicht mit DLCs kompatibel.

### Andere Mods
Diese Mod ist kompatibel mit anderen Mods, solange diese keine der Vanille-Gebäude-Unlocks ändern. Falls andere Mods
neue Gebäude-Unlocks hinzufügen, werden diese nicht modifiziert und funktionieren normal.
