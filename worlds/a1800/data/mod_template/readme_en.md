# Archipelago Randomizer for Anno 1800 - {{ mod_name }}

This mod randomizes Anno 1800 and implements the communication with an Archipelago multiworld.
It was generated for the slot {{ slot_name }} on the seed {{ seed_name }} for Archipelago version {{ ap_version }}.

This mod can be played standalone without any Archipelago client or server if it was the only slot during generation.

## Compatibility
### DLCs
Currently, this mod is not compatible with any DLCs.

### Other mods
This mod is compatible with other mods as long as they don't change the vanilla building unlocks. If other mods add new
building unlocks, they will not be modified and work as usual.
